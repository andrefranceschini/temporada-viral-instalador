# Instalador da Temporada Viral

Arquivo protegido por senha para quem comprou a [Temporada Viral](https://temporadaviral.com). Sem a senha da área
de membros, ele não abre.

Para instalar pelo celular, abra o Claude Code na nuvem no seu repositório e mande:

> Instale a Temporada Viral seguindo https://raw.githubusercontent.com/andrefranceschini/temporada-viral-instalador/main/INSTALAR.md
> A senha é: (a senha da área de membros)
